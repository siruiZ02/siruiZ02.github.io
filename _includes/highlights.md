**Wide Area Networks:** Cross-Layer (Application/IP/Optical) Resource Allocation and Traffic Engineering

- MirrorNet [NSDI 2026]: a twin of the production network for daily management.
- PreTE [SIGCOMM 2025]: a novel traffic engineering system which factors in the dynamic fiber cut probabilities directly through prediction.
- MegaTE [SIGCOMM 2024]: the first TE system that manages fine-grained flows between millions of VMs or containers.
- FlexWAN [SIGCOMM 2023]: a hardware-software optical system that supports reconfigurable fiber spectrum allocation for wide-area networks.
- OpTel [NSDI 2022]: a first optical telemetry system that collect production-level optical layer data at one-second granularity.

**Data Center Networks:**

- MPCCS [Eurosys 2026]: exploit scale-up and scale-out networks for LLM training.
- Holmes [NSDI 2025]: a first system focusing on irregularities (instead of failures) during LLM training.
- P-ECMP [NSDI 2025]: leveraging ECMP programmability for precise traffic control.
- Turbo [SIGCOMM 2024]: an efficient communication framework for big data system consisting of hundreds to thousands of nodes.

**Cloud/Edge Networks:**

- LADR [NSDI 2026]: combining loss avoidance, detection, and recovery to reducing video frame loss in cloud gaming.
- Fornax [SIGCOMM 2025]: shifting management paradigm from software-centric to hardware-centric architecture.
- Tensor [SIGCOMM 2023]: a lightweight approach to implementing BGP non-stop routing.
- Octans [TPDS 2021]: a high-performance service function chains in many-Core Systems.
- Quicksync [Mobicom 2015]: an efficient synchronization system for mobile cloud storage.
